# Impossible Movies

A random movie idea generator. Pick a genre, a film length and an era, press Impossible, and get a title, a year, a cast and a synopsis. Every word is used only once per browser session, so each result is new until the dictionary runs out (reset it under Dictionary Stats).

Made by Andras Kanai.

## Play

Open `index.html` in a browser. It is one self-contained file: no build step, no dependencies. Sound is on by default, the speaker icon mutes it.

## Origin

Ported from the v0 / Next.js version into a single standalone `index.html` (plain HTML, CSS and JavaScript). Word lists, colors, icons and sounds come from the original build.
